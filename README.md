# YouTube-Thumbnail-Downloader

A simple tool to download thumbnail images from YouTube videos.

## Usage

1. Paste a YouTube video URL or video ID
2. Click "Get Thumbnail"
3. View and download the thumbnail image

## Features

- Supports full YouTube URLs and video IDs
- Displays the maximum resolution thumbnail available
- Click the image to open in a new tab for downloading

## Tech Stack

- HTML/CSS/JavaScript
- YouTube thumbnail API
- Hosted via GitHub Pages
